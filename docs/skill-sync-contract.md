# 스킬 다운로드 충돌 계약

`skill download`가 동기화의 공통 진입점이다. `session sync`는 원격 변경을 확인한 뒤 호출하고, `sync download`는 convention router에서 직접 호출한다. 어느 경로도 암묵적인 강제 덮어쓰기를 허용하지 않는다.

manifest v2의 `fileHashes`는 프로젝트 상대 파일 경로별 SHA-256 배포 기준이다. canonical과 각 mirror의 기준을 따로 기록한다. v1 읽기를 유지하며, 기준이 없는 기존 파일은 서버 내용이나 패키지 version이 같아도 원본이라고 추정하지 않는다. 충돌한 패키지는 이전 manifest 항목을 유지한다.

| 상태                                    | 기본 동작                                            | fixture                             |
| --------------------------------------- | ---------------------------------------------------- | ----------------------------------- |
| 최초 설치, 대상 경로 없음               | 설치 후 기준 기록                                    | 빈 임시 프로젝트                    |
| 미수정 파일, 반복 다운로드              | 정상 업데이트                                        | canonical 및 mirror 원본            |
| 로컬 수정/추가/삭제                     | 패키지 전체 보존                                     | 파일 수정, 바이너리 추가, 파일 삭제 |
| 로컬 패키지 전체 삭제                   | 복원하지 않고 충돌 보고                              | canonical 디렉터리 삭제             |
| mirror 수정, 로컬 파일/빈 디렉터리 추가 | canonical도 변경하지 않음                            | mirror 변경                         |
| 서버에서 패키지 제거                    | 모든 기존 경로가 기준과 같을 때만 제거               | 원격 목록에서 제외                  |
| slug 변경                               | 이전 경로 정리와 새 경로 설치를 한 단위로 검사       | 동일 ID의 새 slug                   |
| mirror 대상 축소                        | 제외된 mirror도 동일 검사                            | agents → none                       |
| v1 또는 기준 없는 기존 파일             | 보존 및 충돌 안내                                    | 해시 없는 manifest                  |
| symlink 또는 비정규 경로                | unsafe 원본은 보존, 같은 이름의 unsafe 미러는 건너뜀 | 링크 fixture                        |
| OS 자동 생성 파일                       | 충돌 검사에서 제외                                   | .DS*Store·Thumbs.db·.*\*            |
| manifest 항목·소유권 오류               | 해당 패키지만 보존하고 다른 패키지는 계속            | 잘못된 slug·미러 경로·중복 소유권   |
| stage 이후 로컬 변경                    | commit 직전 재검사로 중단                            | 쓰기 도중 수정 주입                 |
| 중간 적용 실패                          | 이전 패키지 및 manifest 복원                         | rename/write 실패 주입              |

파일 내용은 충돌 출력에 포함하지 않는다. 강제 동작은 `--id`로 선택한 패키지 또는 `--force --all`로 명시한 전체 범위에만 적용한다. v1 일괄 이행은 `--force --all`을 사용하며 자동 동기화에서는 강제하지 않는다. 임시 디렉터리 기반 판별 fixture는 `test/skill-sync.test.ts`, 다운로드 통합 fixture는 `test/skill-download.test.ts`에 둔다.

미러 루트 전체가 없으면 선택된 대상만 재생성하고 원본 갱신을 계속한다. 미러의 개별 파일 삭제·편집·추가는 기존처럼 보존한다. 같은 slug의 설치·갱신 중 안전하지 않은 미러는 해당 루트만 건너뛰고 기존 배포 기준을 유지한다. 원본 경로의 unsafe 또는 안전하지 않은 옛 미러가 남는 이름 변경·서버 삭제는 패키지를 보존한다.

`session sync`는 배포 기준이 있고 원격 version이 같은 정상 패키지의 본문 다운로드를 생략한다. 충돌 패키지만 재검사하므로 정상 패키지까지 매 세션 다시 받지 않는다. `skill download`와 수동 `sync`는 같은 버전도 검사하여 사용자가 미러나 로컬 파일을 정리한 뒤 재시도할 수 있다.
